# 信号争夺

低配置电脑可运行的单机人机射击肉鸽小游戏。**纯前端**，无需安装依赖、无需服务器。

## 启动

直接双击打开 `index.html` 即可游玩（游戏逻辑在浏览器本地运行）。

也可部署到 GitHub Pages 后直接访问网页游玩。

## 操作

- 电脑：`WASD` 移动 · 鼠标瞄准 · 左键/空格射击
- 手机：**左摇杆移动 · 右摇杆瞄准 · 自动开火**（拖动屏幕）

## 玩法

无尽生存：清完一波自动进入下一波，**3 条命**用完即本局结束（正计时存活时间）。击败敌人、拾取能量核心获得经验，升级后可三选一强化（经验随等级递增）；奖励中可能出现**多给一条命**或**增加生命上限**。属性有上限，满级后不再出现对应强化。强化在失去一条命后仍保留。

## 单人玩法提示

- 用电脑玩即可，`WASD` + 鼠标操作。
- 打开页面的设备即为控制端；最后打开/刷新页面并操作的设备持有控制权。
- 请保持**只开一个页面**：手机、旧标签页或多余窗口都会抢走控制权，导致电脑无法移动/射击。
- 若出现移动不了，关闭其他页面的游戏标签、刷新当前页面即可。

> 更新代码后，若之前已运行过 `node server.js`，请先停掉旧进程再重新启动，否则跑的是旧版本。

## 文件

- `game.js`：游戏规则、AI 与经验/升级逻辑（浏览器端）
- `app.js`：输入、渲染、HUD、属性面板与升级界面
- `style.css`：界面样式
- `index.html`：游戏页面
