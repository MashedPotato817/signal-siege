# 信号争夺

低配置电脑可运行的单机人机射击肉鸽小游戏。**纯前端**，无需安装依赖、无需服务器。

## 启动

直接双击打开 `index.html` 即可游玩（游戏逻辑在浏览器本地运行）。

也可部署到 GitHub Pages 后直接访问网页游玩。

## 操作

- 电脑：`WASD` 移动 · 一直自动攻击 · **左键**待机/攻击切换 · **右键**锁定目标自动瞄准 · `空格`临时开火 · `ESC` 暂停
- 手机：**左摇杆移动 · 右摇杆瞄准 · 自动开火**（拖动屏幕）· 右上角 ⏸ 暂停

## 玩法

无尽生存：清完一波自动进入下一波，**3 条命**用完即本局结束（正计时存活时间）。击败敌人、拾取能量核心获得经验，升级后可三选一强化（经验随等级递增）；奖励中可能出现**多给一条命**或**增加生命上限**。属性有上限，满级后不再出现对应强化。强化在失去一条命后仍保留。

**经验**：拾取 1 个能量核心 = **10 经验**；击杀经验按怪种区分——侦察 `+2`、射手 `+3`、重装 `+4`、首领 `+15`。升级所需经验 = `(3+⌊(等级-1)×1.5⌋)×5`（如 15/20/30/35/45…），随等级递增。

**HUD 布局**：左上角为等级 + 红心命数 + 血条（红色数字置顶）+ 经验条（黄色数字置顶）；右上角为波次 + 敌人数与方形暂停键；左下角为属性面板；中央为计时器（Boss 战时暂被 Boss 血条替代）；右下角为游戏名。

- **敌人成长**：小怪（侦察/射手/重装）的血量与伤害随波数递增，越到后期越硬。
- **三种首领**：每 3 波出现，轮流登场——普通首领（三连发）、**喷火首领**（朝玩家方向扇形喷火，范围伤害）、**堡垒首领**（血量极高、移速极慢、近战重击）。Boss 存活时顶部中央显示**Boss 血条**（代替计时器，计时仍继续），死亡后恢复。Boss 出场时周围会跟随一批小怪。
- **掉落道具**：小怪有概率掉落、首领必掉。包括**血包**（回复 45 生命）与三种 8 秒临时增益——**怒火**（攻击 +50%）、**超频**（攻速 +60%）、**射程增幅**（子弹射程 +80%）；临时增益**可突破属性上限**，右上角显示倒计时。

## 文件

- `game.js`：游戏规则、AI 与经验/升级逻辑（浏览器端）
- `app.js`：输入、渲染、HUD、属性面板与升级界面
- `style.css`：界面样式
- `index.html`：游戏页面
