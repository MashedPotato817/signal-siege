# 信号争夺

低配置电脑可运行的单机人机射击小游戏。无需安装依赖。

## 启动

在本目录运行：

```powershell
node server.js
```

然后打开 `http://localhost:3000`。若提示 3000 端口被占用，先关闭此前运行的 Node 服务再重试。

## 操作

- `WASD`：移动
- 鼠标：瞄准（虚线会显示射击方向）
- 鼠标左键 / 空格：连续射击

## 玩法

在 90 秒内抢夺能量核心，并击败行为随机的 AI 对手。每获得 3 枚核心会暂停并出现三选一局内强化：射速、移动或伤害。强化在本局死亡后仍会保留，但下一局重置。

## 单人玩法提示

- 用电脑玩即可，`WASD` + 鼠标操作。
- 打开页面的设备即为控制端；最后打开/刷新页面并操作的设备持有控制权。
- 请保持**只开一个页面**：手机、旧标签页或多余窗口都会抢走控制权，导致电脑无法移动/射击。
- 若出现移动不了，关闭其他页面的游戏标签、刷新当前页面即可。

> 更新代码后，若之前已运行过 `node server.js`，请先停掉旧进程再重新启动，否则跑的是旧版本。

## 文件

- `server.js`：游戏规则、AI 和实时服务
- `app.js`：输入、画面和升级界面
- `style.css`：界面样式
- `index.html`：游戏页面
